Computer scientists can utilize this course by creating their own intelligent systems to assist them in solving problems. The problems best solved are those that are
dynamic with many variations. Static tables are difficult to create for such problems and using an agent supported by a neural network to learn at a faster rate than we can, 
although requires more guidance than we, can be one of the fastest and best solutions to such a problem.
